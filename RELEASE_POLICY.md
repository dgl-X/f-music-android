# Накопительные Android-выпуски

Небольшие дефекты записываем в `KNOWN_ISSUES.md` и накапливаем, обычно по 3–7
исправлений на тестовый выпуск. Коммит не означает автоматический новый APK:
версию и release tag повышаем для всего набора.

Сначала запускаем тесты и выпускаем подписанный APK в приватном репозитории,
проверяем его вместе с сервером на production в обычном использовании. После
подтверждения WEB и Android переносим проверенный набор в публичный канал.
Новая мелочь добавляется в список; отдельный релиз на каждое замечание не
создаётся автоматически. Критический сбой рассматривается отдельно.
