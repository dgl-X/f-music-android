# Полевая проверка Android 1.0.59

3–4 дня обычного использования с сервером 0.1.35. Это предварительный
стабилизационный выпуск; автоматические тесты не подтверждают все реальные сети
и устройства. Устанавливать поверх предыдущего APK без сброса данных.

- Запуск, возврат из фона, MP3/FLAC, перемотка, shuffle и предыдущий трек.
- WEB играет → телефон управляет → перенос на телефон → обратно на WEB.
  Проверить название, обложку, позицию, play/pause и команды из шторки.
- Очередь WEB на телефоне: названия и исполнители, текущий трек, страницы,
  обновление. Просмотр не должен переносить музыку или менять локальную очередь.
- Переходы Wi-Fi/LTE, короткий обрыв, выключенный экран. После восстановления
  интерфейс сверяется с исполнителем; нажатия не исполняются повторно.
- Сохранённые песни без сети, сохранность кэша/загрузок после обновления.
- Два аккаунта: устройства и команды Connect принадлежат только своему аккаунту.

При сбое сразу отправить отчёт из приложения, желательно до перезапуска:
журнал относится только к текущему процессу. Написать, кто исполнял музыку,
откуда нажималась команда, что получилось, время и наличие смены сети.
Не присылать пароли или токены. FM-ANDROID-016/017/018 до подтверждения не закрывать.

Мелочи накапливаем, а не выпускаем APK после каждого замечания. ANR при старте,
потеря данных, нарушение изоляции или массовый отказ воспроизведения требуют
прервать проверку и откатить неисправную версию. Большие функции пока не добавляем.
