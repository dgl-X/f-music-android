# Участие в разработке Android

Перед Pull Request создайте Issue для крупного изменения и убедитесь, что оно
совместимо со стабильным `/api/v1` сервера.

```bash
./gradlew --no-daemon testDebugUnitTest assembleDebug
```

Не добавляйте release-keystore, signing properties, session cookie, адрес личного
сервера, диагностические отчёты пользователей, APK или офлайн-медиатеку. Новый
код должен сохранять работу без сети для уже скачанных треков и корректно
переживать смену Wi-Fi/LTE/VPN.

Изменения распространяются на условиях GPL-3.0-only.
