# Политика безопасности Android

Уязвимости Android-клиента следует сообщать приватно через **Security → Report a
vulnerability** в основном серверном репозитории Family Music. Не публикуйте
session cookie, адрес домашнего сервера, диагностический отчёт с персональными
данными, release-keystore или пароли подписи.

Поддерживается последняя стабильная версия приложения. В сообщении укажите
версию, модель устройства, Android API level, сетевые условия и минимальные шаги
воспроизведения. Полная политика и границы проекта описаны в серверном
[`SECURITY.md`](https://github.com/dgl-X/f-music/blob/main/SECURITY.md).
